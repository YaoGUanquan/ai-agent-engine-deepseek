# 界面验证

使用项目已有框架和可用浏览器能力，不为一次验证搭建新的工具平台。

- 在项目支持的桌面与移动视口检查文字溢出、遮挡、布局稳定性和可操作区域。尊重现有设计输入，不擅自重做视觉风格。
- 检查语义结构、表单标签、键盘操作、焦点可见性、错误反馈和必要的读屏信息。动画应有减少动态效果的可用替代。
- 对目标路径验证加载、空、成功、失败、权限不足和重复提交等适用状态；网络请求成功不能代替页面行为正确。
- 有视觉要求时读取本次截图并核对内容；需要精确定位时查看元素结构、计算样式和布局数据。文件存在不等于画面已通过。
- 复用已隔离的数据和会话，只清理本轮拥有的资源。登录态、截图、网络附件可能含敏感数据，不上传、不写入公开仓库。
- 缺少浏览器、服务、认证或隔离条件时，继续可独立完成的静态工作，将依赖项标为阻塞，不宣称已通过浏览器验收。
